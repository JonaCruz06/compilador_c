# Proyecto de Compiladores: Diseño del Front-End

El proyecto incluye las fases de análisis léxico, análisis sintáctico y análisis
semántico. El lenguaje diseñado permite declaraciones de variables, asignaciones,
expresiones y estructuras de control con soporte para anidamiento.

## Fases del compilador

- Análisis léxico.
- Análisis sintáctico.
- Construcción del Árbol de Sintaxis Abstracta.
- Análisis semántico.
- Validación de tipos.
- Manejo de tabla de símbolos.
- Control de ámbitos.

## Estructuras de control soportadas

- if
- if-else
- if-elseif
- for
- while
- do-while
